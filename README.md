# Radwan Sheet

Personal planner for Radwan's life, schedule, notes, and future additions.

## What is included

- Personal-life dashboard sections for Today, Goals, Habits, Family & Friends, Health, Travel, Wishlist, and open space.
- A month-style schedule covering 11 September–10 October 2026 in Riyadh time (UTC+3).
- A read-only embedded Google Docs notes preview.
- Owner-only edit links for the GitHub Pages source and the Google Doc.

## GitHub Pages

The site is a single static `index.html` file and publishes from the root of the `main` branch using GitHub Pages.

Public site: https://radwan22s.github.io
